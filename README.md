# Tiny Rogues 简体中文汉化补丁 v1.6.2

基于社区汉化补丁 `TinyRogues_zh_CN_v1.5.26` 优化制作，在原有基础上系统性地精修了武器 / 装备描述、补齐剩余类别并统一了社区术语。

## v1.6.2 更新内容（相对 v1.6.1）

- **发布包精简为纯翻译版**：仅包含翻译与对话框优化功能（TinyRogues.TmpFallback + XUnity.AutoTranslator + 全部词典）。
- **移除所有测试/诊断插件**：KeyCapture 文本抓取、ClassProbe 探测、开局属性修改模组（幸运/掉宝率/诅咒/资源等）、热切换脚本等，这些只会在汉化测试环境使用，普通玩家不需要且会导致不必要的卡顿/掉帧。
- **玩家体验**：下载后覆盖到游戏根目录即可，正常游玩不受干扰。

## v1.6.1 更新内容（相对 v1.6.0）

- **金属吉他终于完全修复**：根源是效果行单词之间的 NBSP（U+00A0）不匹配导致整卡落空、回退片段混排；改为中英双分支整卡正则，同时覆盖纯英文源与片段混合残留两种形态。
- **时之笛·有害物附魔变体**：Legendary Instrument 整卡正则（施加 Echo, Necrosis），与既有 Occult 变体（Echo, Gloom）并行。
- **附魔变体整卡补全**：矩阵圣经·神圣（Virus, Glitter）、星辰加农炮·电击（Shock, Glitter）、班卓琴·电击（Shock, Echo）等附魔变体都补上中英双分支整卡正则。
- **术语纠正**：暴风扇效果“冰旋”→“冰龙卷”（Icy Twisters，按社区规范）；星辰加农炮效果按规范为“技能使用时触发一道星辰爆炸，造成X至Y点法术伤害”。
- **正则规模**：TMP 正则 2302 条全部通过 .NET 编译。

## 本版优化内容（相对 v1.5.26）

- **武器描述精修**：逐类检查并修复魔杖、法杖、矛、连枷、剑、投掷、弓、弩、魔典、卷轴、权杖、炮、扇、乐器、棍棒等全部类别的描述，解决「中英混杂」「语序混乱」「数值错位」「残留 `$8/$9` 占位符」等问题。
- **描述补全**：补充翻译了此前未覆盖的武器独特效果行、详细效果说明、技能卡（如流星 / 小鬼）与状态效果卡，并统一按游戏规范将状态说明缩小显示。
- **正则体系修复**：修复批量武器卡正则捕获组偏移（导致属性加成 / 攻击伤害 / 攻击速度互相串位）、NBSP（不间断空格）不匹配、`+$7%` 双重符号等问题；现正规模块 2302 条全部通过 .NET 编译。
- **术语统一**：依据社区整理的中文名词术语表（装备 / 符咒 / 武器 / 词条 / 状态等），统一「能量 / 黯蚀 / 防御射线 / 寒冷效果」等用词，消除同词异译。
- **词典规模**：主字典 `TinyRogues_zh.txt` 约 9700 条、TMP 正则 2302 条、片段 2116 条、对话 1605 条。

## 安装方法

1. 关闭游戏。
2. 将本文件夹内的 **所有内容**（`BepInEx/`、`dotnet/`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`SourceHanSans_U2022` 等）**复制并覆盖**到游戏根目录，即 `steamapps/common/Tiny Rogues/`。
3. 正常启动游戏即可。首次加载会生成 IL2CPP 互操作程序集与汉化缓存，之后所有界面、物品、技能、描述均为中文。

> 若游戏目录之前已装过旧版汉化，直接覆盖即可；本补丁已包含完整的 BepInEx + XUnity.AutoTranslator 框架，无需额外安装。

## 目录说明

- `BepInEx/Translation/zh/Text/TinyRogues_zh.txt` —— 主翻译字典（核心文件）。
- `BepInEx/plugins/TinyRogues.TmpFallback/` —— 运行时兜底层（正则 / 片段 / 对话词典，对动态串做精准翻译）。
- `BepInEx/plugins/XUnity.AutoTranslator/` —— UGUI 文本自动翻译框架。
- `dotnet/`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` —— BepInEx 运行依赖（IL2CPP 注入）。
- `SourceHanSans_U2022` —— 思源黑体中文字体（支持中文显示）。

## 已知限制（非翻译缺口）

- 富文本标签相邻的连接介词（`at` / `of` / `on` / `for` / `as` / `to` 紧贴 `</color>` 标签）为 XUnity 引擎固有限制，强行用裸碎片补全会破坏复合词，故保留。
- 怪物拟声词（如 `Zi-k`、`R-RO`）、平台名 `Steam Deck` 等按惯例保留英文。
- 游戏更新后（`GameAssembly.dll` 变化）插件翻译可能部分失效，需等待汉化适配新版本。
